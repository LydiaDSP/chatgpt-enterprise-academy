# V1.1 第三批验收单｜Work / Computer Use + IE / IT扩展

> 项目：ChatGPT Enterprise Academy（制造业跨部门AI教学）。本批位于独立分支 `feat/v1.1-phase3-work-roles`，验收前不合并 `main`。

## 交付范围与边界

- `labs/work.html` + `labs/work.js`：Work / Browser Use / Computer Use 三种能力的概念比较、三个模拟任务流程、权限决策练习、模拟审批及操作日志。
- `labs/roles.html` + `labs/roles.js`：IE 6个、IT 6个岗位场景。每个包含输入、可复制Chat指令、未来Agent方案、预期产物、验收和安全边界。
- `samples/IE_线平衡_模拟.csv` 和 `samples/IT_设备在线事件_模拟.csv`：100%虚构的学习数据。
- 首页原 `page-work` 与 `page-cases` **只新增专题入口**，不重写已有交互。
- Prompt Lab由另一个窗口开发，本批没有修改 `page-prompt` 对应HTML或 `PROMPT_TASKS`。
- 原Excel对应的 **30条、6个部门场景不变**；新增12个场景是教学拓展，不得标为原表需求或公司已部署案例。

## 人工验收A：Work / Computer Use

| 编号 | 操作 | 应看到 |
| --- | --- | --- |
| WK-01 | 选择“公开物流资料对比” | 默认有5步任务流程、目标、权限边界 |
| WK-02 | 切换“模拟日报”和“设备离线核查” | 任务说明与步骤即时更新；没有触发真实网站/设备连接 |
| WK-03 | 按步骤“下一步/上一步” | 标题、任务动作、观察点同步变化；首末步正确禁用 |
| WK-04 | 权限练习依次选择：可继续 / 禁止 / 等待审批 / 禁止 | 参考得分4/4，且可查看判定解释 |
| WK-05 | 不申请审批直接尝试“模拟执行” | 按钮禁用 |
| WK-06 | 先请求，再模拟批准，再模拟执行 | 仅模拟状态变化，并有顺序日志，界面明确没有发送消息 |
| WK-07 | 重置审批 | 再次禁止直接模拟执行 |
| WK-08 | 勾选业务交付5项并刷新 | 勾选记录保留在当前浏览器；不向服务器上传记录 |
| WK-09 | 切换场景并复制任务 | 可以复制到公司授权账号作为演示指令，但网页自身未执行Agent |

## 自动验收

GitHub Actions：`Academy V1.1 Acceptance` 应依次通过：

1. `node tests/verify.mjs`：原始课程及30场景一致性
2. `node tests/browser-smoke.mjs`：原有导航、Prompt、Codex小工具
3. `node tests/labs-smoke.mjs`：Research、Codex、Skill
4. `node tests/phase3-smoke.mjs`：Work权限/审批流程、IE/IT 6+6、原始数据保持不变

> CI是DOM层的互动冒烟验证，不是对真实云端Work或受管控电脑操作的端到端验收；投影显示、Chrome/Edge、企业账号权限需要讲师另测。

## 安全与教学真实性

- 禁止用教学模拟功能宣称完成真实物流服务商调研或生产设备排查。
- 不上传真实WinCC、网关、无线网络、ERP、MES或终端安全日志到公共网页。
- 任何生产/网络配置写入、外发邮件与数据变更都应留在获批准的控制流程中。

## 教学落地建议

- Work主课程15分钟：先讲产品分工，再选择“公开资料”做任务/权限判断，重点展示人工审批（8分钟）；其余任务交课后。
- IE/IT扩展：现场10分钟仅示范各1条，其余案例供学员课后独立练习。
- 正式授课前用企业测试账号在合法环境真实彩排一次，准备失败时的备用截图/录屏。
