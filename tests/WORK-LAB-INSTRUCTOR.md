# Work & Computer Use 讲师现场演示指南

本指南服务正式课堂彩排，**不是企业系统操作授权**。

## 课堂最小演示：公开资料比较
1. 打开 `labs/work.html`，选“公开物流资料对比”，说明任务输入、输出与来源限制。
2. 点击“下一步”展示：计划→只读访问→整理→人工复核。提醒网页不是真的访问网站。
3. 打开已经准备好的企业测试账号，尝试同样的公开资料阅读任务。检查允许的网站、文件权限、提示与请求批准动作；如果当前工作区不支持，不强行绕过策略。
4. 使用“权限决策实验”的4题进行学员投票，讨论“公开只读”“未经审批上传”“对外发送”“重启生产设备”之间的区别。
5. 进行模拟审批：请求→模拟同意→模拟执行→日志，强调没有真实发送或修改。

## Computer Use 演示选项
- 优先演示**模拟截图和测试应用**，不使用真实生产控制软件。
- 用户授权与管理员策略要分别满足；应用或网站不在允许范围时停止。
- 业务文件先脱敏，记录验证来源与执行边界。
- 无法获得合法操作环境时仅讲演练逻辑，不假装已经执行。

## 何时切换备用方案
- 账号或权限缺失：使用网页练习台讲解权限与审批。
- 模型执行耗时不可控：使用经审核的事先录屏讲解关键事件，不将录屏当作现场结果。
- 无法验证结论出处：在交付报告标注未核实，不发布为业务决定。

## 检查完成的证据
- 任务目标清晰，来源和范围已批准
- 操作过程可追踪、关键操作有审批
- 生成结果能核对事实，未知项有标记
- 设备/系统修改和对外传播不属于现场教学自动化
