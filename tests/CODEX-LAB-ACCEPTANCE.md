# Codex AI Coding 示范｜课堂可复现步骤

此文档供讲师彩排和故障备用，不把网页内JavaScript与Codex模型执行混为一谈。

## 准备
- 本地创建独立空白文件夹，例如 \`codex-order-demo\`。
- 下载仓库 \`samples/采购订单_模拟_1.csv\`、\`_2.csv\`、\`_3.csv\`，复制进该文件夹。
- 在公司授权的Codex产品中打开此文件夹；确保已明确文件读写范围。
- 不使用真实订单、供应商信息或生产系统账号。

## 推荐演示流程（15–20分钟）
1. **描述任务**：打开 \`labs/codex.html\`，复制第一阶段需求，让Codex先复述；要求说明重复键、保留原始记录与输出。
2. **检查样例**：复制第二阶段指令，让Codex计算预期行数和异常，确认输入约束。
3. **开发最小工具**：复制第三阶段指令，让Codex在练习目录创建可运行工具，执行并展示输出。
4. **补充测试**：复制第四阶段指令，重点检查三份样例9行、2行异常、缺少表头、非法数量、包含逗号的引号字段与CSV公式注入。
5. **完成交付**：复制第五阶段指令，说明脚本、运行方式、测试证据、限制与可回滚方法。

## 标准输入/答案
- 3份模拟CSV，合计9行数据（不计表头）。
- 1条重复键：\`PO-002 + MAT-B\`。
- 1条缺失交期：\`PO-008 + MAT-E\`。
- 不应自动删除任何重复行。
- 同一订单号、不同料号不等于重复键。
- 网页实验室的挑战数据为4行、3行包含异常，作为补充边界测试。

## 失败时如何处理
- Codex权限或登录故障：改用网页离线CSV工具展示真实的输入和输出，明确它不是Codex。
- 运行时失败：展示测试失败、错误信息和后续修复步骤，不要临时声称任务已经完成。
- 时间不足：提前录制经过审查的真实操作，现场讲解关键检查点。

## 风险与后续
- 用户真实CSV的数据权限、文件编码、列差异、日期口径可能与模拟数据不同。
- 浏览器本地演示工具只负责CSV，不支持.xlsx或生产系统直接连接。
- 编码或公式注入保护是防线之一，不替代受控环境和安全评估。
