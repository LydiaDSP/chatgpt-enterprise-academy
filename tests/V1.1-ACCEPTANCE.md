# V1.1 第一批｜验收单（开发分支）

> 范围：讲师导航 / 投影大字 / 场景深链 / 案例数据同步 / 既有交互回归。未合并至 main，不代表正式授课版已经完成。

## 如何查看这一批

1. 打开本 PR（由开发分支 feat/v1.1-phase1-teacher-experience 提交）。
2. 进入该分支 Code → Download ZIP，解压后**从文件夹根目录**打开 index.html（不要只下载单个 HTML，否则示例 CSV 无法下载）。
3. 使用桌面 Chrome 或 Edge 进行以下测试。若仓库后续部署了分支预览，可直接在预览网页测试。

## 人工验收场景

| 编号 | 步骤 | 应看到 |
| --- | --- | --- |
| T01 | 首页点击右上角“下一章”，再点击“上一章” | 先进入桌面端章节，再返回首页；首页“上一章”不可点 |
| T02 | 点击右上角“投影大字”两次 | 第一点击正文、表格、案例字号变大，第二次恢复；按钮可切换 |
| T03 | 开启“讲师模式”，按 Shift + PageDown、Shift + PageUp | 进入下一章节、返回上一章节，不触发浏览器前进/后退 |
| T04 | 地址栏在 index.html 后添加 #dept-QA 并回车、刷新 | 定位业务案例页的品保部门，地址栏保留 #dept-QA |
| T05 | 地址栏在 index.html 后添加 #case-01 并刷新 | 进入业务案例页面，自动展开 case-01 |
| T06 | 切换为“自学模式”并刷新 | 上次选择的模式保留；不显示讲师专属提示 |
| T07 | 开启投影大字后刷新 | 大字模式继续生效（使用同一个浏览器、同一个页面来源） |
| T08 | 打开Codex章节，点击“载入内置模拟订单”→“运行合并与检查” | 3份文件、9条记录、2条异常记录，可下载两份CSV |
| T09 | 打开Prompt Lab，切换到“缺料分析” | 提示词实时更新为缺料分析；检查要点继续显示 |
| T10 | 在“业务场景指南”点击品保部门导航按钮 | URL切换到 #dept-QA，页面滚动到正确的部门 |

## 自动验收

- `node tests/verify.mjs`：静态结构、JavaScript语法、30场景唯一性及数据一致、CSV数据文件、120分钟课程结构。
- `npm install --no-save --no-package-lock --ignore-scripts jsdom@26`
- `node tests/browser-smoke.mjs`：模拟交互验收，验证深链、前后章节、投影、快捷键、Codex CSV工具和Prompt切换。
- 同时会在 GitHub Actions `Academy V1.1 Acceptance` 工作流中运行以上检查（以实际执行结果为准）。
