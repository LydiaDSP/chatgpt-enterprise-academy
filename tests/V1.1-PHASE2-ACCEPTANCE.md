# V1.1 第二批｜教学专题验收单

范围：Deep Research、Codex、Skill 三个**独立教学实验室**。Prompt Lab由其他分支开发，本批不修改其教学代码或界面。

## 预览

进入功能分支 `feat/v1.1-phase2-research-codex-skill` 下载整个仓库ZIP，解压并双击根目录 `index.html`。分别点击：
- 文件与数据 → Deep Research实验室
- Skill/MCP/Plugin → Skill实验室
- Codex → Codex开发实验室

也可直接打开 `labs/research.html`、`labs/skill.html`、`labs/codex.html`。不要只下载一个HTML，否则CSS/JS或文件链接会缺失。

## 实验室A：Deep Research

| 编号 | 操作 | 预期 |
|---|---|---|
| DR-01 | 选择“设备预测性维护” | 研究任务单自动变成对应选题，输出目标/来源/交付结构 |
| DR-02 | 修改研究边界和目标读者 | 任务单动态更新，可以复制 |
| DR-03 | 点四个教学步骤 | 显示明确问题、审阅研究计划、证据核查、成果验收 |
| DR-04 | 对3个模拟证据分别选择参考答案 | 已判断3/3，正确3/3，且可展开判定依据 |
| DR-05 | 勾选5条报告检查标准并刷新 | 验收进度保留；不显示伪造的研究报告 |

## 实验室B：Codex

| 编号 | 操作 | 预期 |
| --- | --- | --- |
| CD-01 | 点击5个开发阶段 | 指令与讲师提示同步变化；可复制到真实Codex |
| CD-02 | 点击“载入3份标准模拟订单”→运行合并 | 显示9行、2行异常；保留源文件和行号 |
| CD-03 | 点击“载入挑战数据”→运行合并 | 显示4行、3行异常，含重复、无效数量、缺失交期/主键 |
| CD-04 | 运行6项测试 | 全部通过；包括CSV双引号、缺失列、非法数量、CSV导出防公式执行 |
| CD-05 | 下载合并结果和异常清单 | 生成两个带UTF-8 BOM的CSV，源文件没有被修改 |
| CD-06 | 选择缺列CSV进行处理 | 明确错误，不产生看似成功的结果 |

注：网页中的程序是独立 JavaScript 教学工具，不是 Codex 在后台实时开发；真实Codex体验必须在授权环境完成。

## 实验室C：Skill

## 自动化验收

GitHub Actions 的 `Academy V1.1 Acceptance`：
1. 原有 `node tests/verify.mjs` 与 `node tests/browser-smoke.mjs` 必须保持通过。
2. 新增 `node tests/labs-smoke.mjs` 测试3个专题页面的核心交互。
3. CI通过不代替Chrome/Edge/投影实测、企业工作区的真实能力验证。
