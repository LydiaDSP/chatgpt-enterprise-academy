# SOP差异审查输出字段规范

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 编号 | 是 | CHG-001 起的顺序号 |
| 章节/控制点 | 是 | 操作步骤、参数、抽样、校准、审批等 |
| 变化类型 | 是 | 新增 / 删除 / 修改 / 仅格式变化 |
| 旧版内容 | 是 | 原文，缺失时标注“未提供” |
| 新版内容 | 是 | 原文，缺失时标注“未提供” |
| 证据位置 | 是 | 旧/新版各自的章节、页码、行号或原始标题；不编造 |
| 潜在影响（待验证） | 是 | 质量、交付、设备、追溯或合规的可能影响，明确不是结论 |
| 建议复核责任方 | 是 | 可提出 QA / 工艺 / 设备等建议，实际责任归属待确认 |
| 验证动作 | 是 | 如复核工艺窗口、验证抽样计划、确认培训/校准要求 |
| 状态 | 是 | 待人工确认 / 已有证据需复核 / 无法判定 |
